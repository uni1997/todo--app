# todo--app

`index.html` 파일 하나로 동작하는 할 일 목록 앱입니다. 설치나 외부 라이브러리 없이 브라우저에서 바로 실행됩니다.

## 기능

- **할 일 추가**: 입력창에 쓰고 "추가" 버튼 또는 Enter
- **완료 체크**: 체크박스를 누르면 취소선으로 표시
- **삭제**: 각 항목의 ✕ 버튼
- **자동 저장**: 브라우저 저장소(localStorage)에 저장되어 새로고침하거나 브라우저를 다시 열어도 유지
- 남은 할 일 개수 표시, 다크 모드·모바일 화면 지원

## 사용법

1. `index.html` 파일을 내려받습니다.
2. 브라우저(Chrome, Edge, Safari 등)로 엽니다.

## 참고

- 할 일은 사용하는 브라우저에만 저장됩니다. 다른 기기나 다른 브라우저와는 공유되지 않습니다.
- 브라우저의 사이트 데이터를 지우거나 시크릿 모드를 쓰면 목록이 사라질 수 있습니다.
